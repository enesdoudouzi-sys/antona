Eine kleine Strategie

1. Aufgabe anschauen.

2. Einen Schritt nach dem anderen machen.

3. Bei Ablenkung kurz stoppen und freundlich zur Aufgabe zurückkehren.

4. Danach prüfen: Brauche ich Hilfe oder eine Pause?

Stimme klingt robotisch? So bekommst du eine natürliche

Die Stimme kommt vom Gerät, nicht von der App.
• Android: Einstellungen → „Sprachausgabe" → „Google Sprachausgabe" wählen und deutsche Stimme herunterladen.
• iPhone/iPad: Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch → eine (Premium/Erweitert)-Stimme laden.
• Windows/Chrome: meist ist „Google Deutsch" schon natürlich – oben auswählen.
