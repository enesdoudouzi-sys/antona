# Lernsterne (antona)

Kindgerechte Lern-App für die 1.–2. Klasse: Rechnen (forschungsbasiert, mit Zehnerfeld und Mengenbildern), Lesen, Formen & Farben und die Uhr. Mit Sternen und Vorlesefunktion.

**Live:** https://enesdoudouzi-sys.github.io/antona/

Einfach `index.html` im Browser öffnen – kein Server nötig.
